{namespace} = the free-text prefix on the left, so the customer's own naming standard applies (in the hostname lower-cased; spaces and other characters not allowed in a host name become -). {nn} = two-digit index, {nnn} = three-digit, {n} = plain index. Optional: {cluster} (the VMware cluster below), {vbr} (the VBR key), {datacenter} and {location}. With a search domain the hostname stays a short name: the domain goes to dnssearch and the VBR registers hostname.domain (vbrname). Without one, add the domain to the pattern for FQDNs, e.g. {namespace}-{nn}.corp.example. The VM name pattern sets the name in vCenter (column vmname; underscores kept), e.g. {datacenter}_km_{hostname} gives ros_km_vpr-nodspa0101 for the hostname pattern {location}-{cluster}{nn}. Literal text such as km is kept as typed. The VM/Host group is an existing DRS VM group of the cluster (column vmgroup); {cluster} is the cluster name, e.g. vmgr-{cluster}. Keep the part before the first dot within 15 characters (NetBIOS); the table warns when it is longer. The start index continues an existing series that matches the pattern.

Second network adapter (optional: backup / storage network, no default route)

Fills columns ip2, netmask2, portgroup2 (IP counts up per node). The VM gets a second adapter; the installer gives it a static address without gateway or DNS, NIC 1 keeps the default route. Leave the IP empty for one adapter.

Per-proxy sizing

project default 6 / 12 / 120, no data disk

Veeam minimum for the appliance is 2 cores / 8 GB / 120 GB. Rows with more than 2 task slots per vCPU get a warning; the classic rule of thumb is about 1 core and 2 GB RAM per concurrent task.

How this fits the deployment

1. Build the fleet here. Fix every red issue; amber ones are judgement calls.

2. Export the CSV and copy it, the base 13.1 ISO and one settings file per VBR to the deploy host.

3. Run the generated Validate command first, then What-if, then the real run, one VBR at a time.

The CSV columns are exactly what Deploy-VeeamProxies.ps1 reads. Optional columns are exported only when a row uses them: ip2, netmask2, portgroup2 (a second network adapter with a static address and no default route; all three together), gatewayrepo (for role gateway or viproxy+gateway: existing Dell Data Domain / HPE StoreOnce repositories, ;-separated, whose gateway server list gets this appliance), dnssearch (DNS search domains, ,-separated, set on NIC 1), vmname (the VM name in vCenter when it differs from the hostname), vmgroup (an existing DRS VM group of the cluster the VM is added to), handshakecode (an appliance re-homed from another VBR) and vbrname (the FQDN or IP the VBR should use to add the proxy when it differs from the kickstart hostname, for example when DNS has no record yet).
